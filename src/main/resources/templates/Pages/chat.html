Configurações do Banco de Dados

Banco padrão após o cadastro

Ao criar sua conta, o sistema associa automaticamente um banco de demonstração MySQL local:

  • URL: jdbc:mysql://localhost:3306/rede_lojas_roupas
  • Usuário: root
  • Senha: em branco

Isso exige MySQL acessível em localhost:3306 com o schema rede_lojas_roupas. Para usar outro banco, preencha o formulário abaixo e clique em Salvar.

Campos do formulário

Use três campos independentes: URL, Usuário e Senha. Você pode informar usuário e senha nos campos ou embutir na URL — não é necessário fazer os dois ao mesmo tempo.

Formatos de URL aceitos

  • URL JDBC completa: jdbc:postgresql://host:porta/banco, jdbc:mysql://host:porta/banco, etc.
  • Formato curto (sem jdbc:): postgresql://, mysql://, mariadb://, sqlserver:// ou oracle:// — o sistema adiciona jdbc: automaticamente.
  • Credenciais na URL: postgresql://usuario:senha@host:porta/banco — nesse caso, Usuário e Senha podem ficar vazios.
  • SQLite: apenas URL JDBC completa, ex.: jdbc:sqlite:/caminho/para/arquivo.db (em geral sem usuário nem senha).
  • Oracle: prefira o formato oficial, ex.: jdbc:oracle:thin:@host:1521:SID ou jdbc:oracle:thin:@//host:1521/servico.

Exemplos:

  • jdbc:postgresql://localhost:5432/meubanco
  • mysql://localhost:3306/meubanco
  • jdbc:sqlite:/var/dados/app.db

Ao salvar

A aplicação testa a conexão antes de gravar. Se falhar, nada é salvo e uma mensagem de erro é exibida. A senha é armazenada criptografada; credenciais embutidas na URL são removidas da string salva.

Bancos suportados

PostgreSQL, MySQL, MariaDB, SQL Server, Oracle e SQLite.
